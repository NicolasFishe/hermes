# Hermes Privacy Policy

Hermes is personal automation software operated by Nicolas Fishe for his own use, running on his own server. It connects only to Nicolas Fishe's own Google account.

Hermes accesses Gmail and Google Calendar data solely to run the owner's own automations, such as scheduling travel time blocks and processing event invitation emails. All data is stored only on the owner's own server. No data is sold, rented, shared, or transmitted to any third party, and no data is used for advertising.

The owner may revoke Hermes' access at any time from the Google Account permissions page. Questions: nicolasfishe@gmail.com.
